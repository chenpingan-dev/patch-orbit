# Contributing

Start with a small, reproducible input and the expected result. Use synthetic fixtures, never private logs or company source. Include a test when changing analysis behavior. UI changes should work in Chinese and English, with keyboard controls and Microsoft YaHei on Windows.

Open an issue before expanding the supported input format or analysis scope. The goal is a useful, focused tool, not a generic agent platform.

This is an independent, AI-assisted project. Examples are synthetic; no upstream implementation or company code is included.
